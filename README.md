# Unpair BT

Android app that lists the phone's paired Bluetooth devices and unpairs one or many at once.

**Download:** [UnpairBT-2.0.apk](https://github.com/Troubadour42/Unpair-BT/releases/download/v2.0/UnpairBT-2.0.apk)

Version 2.0 puts Light and Dark in a smaller pill at the top right, and crops the in-app icon so the Bluetooth mark fills it like the home-screen icon. The list still shows the name you set in Bluetooth settings.

## Install

1. Download `UnpairBT-2.0.apk` on the phone, or download it on a computer and copy it over.
2. Open the file and install over the existing app. If Android says the package conflicts, uninstall Unpair BT first, then install this one.
3. If Android blocks the file, allow installs from that app (Chrome or Files).
4. If Play Protect warns you, choose More details, then Install anyway. This app is not on the Play Store.
5. Open Unpair BT and allow Nearby devices.

## Use

- Hold a device to select several, then tap Unpair.
- Swipe a row left to unpair just that one.
- Tap Light or Dark at the top right to switch the theme. The choice is remembered.
- The app asks before it forgets a device. Pairing cannot be restored from the app.

Android hides unpairing from apps, so some phones block it. If a device stays in the list, forget it in Settings.
